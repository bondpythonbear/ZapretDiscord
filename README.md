> Один и тот же инструмент могут применять как безопасные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует файлы WinDivert как инструменты повышенного риска или хакерские утилиты. В результате файл удаляется и помещается в карантин. В таком случае обнаружение обычно называется `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте папку zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы хорошо понимаете настройки исключений, предпочтительнее добавить необходимую папку в исключения. При отсутствии уверенности рекомендуется отключить детектирование PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome активируйте пункт "Использовать безопасный DNS" и выберите DNS-провайдера, отличного от "Поставщик по умолчанию"
    * В Firefox откройте настройку "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет включить Secure DNS непосредственно в параметрах системы — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Этот вариант рекомендуется пользователям Windows 11
    * При использовании роутера Keenetic включите в его настройках "Транзит запросов". Отключение этой опции способно помешать настройке и работе Secure DNS на компьютере

2. Получите zip/rar-архив с [последнего релиза](https://github.com/bondpythonbear/zapret-discord-youtube/releases/latest)

3. Откройте свойства скачанного архива и установите флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот пункт можно не выполнять

4. Извлеките файлы в каталог, в пути к которому отсутствуют кириллические буквы и специальные символы

5. Запустите требуемый файл
    * Для поиска подходящей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для включения запуска вместе с системой выберите **`service.bat`** -> `Install Service` -> *нужная стратегия*

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Этот способ подходит для проверки отдельных стратегий. Результат зависит от множества условий, поэтому **перебирайте разные варианты (ALT, FAKE и другие), пока не найдёте подходящий именно для вас**

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавление выбранной стратегии в автозапуск через services.msc</ins>
  - **`Remove Services`** — удаление стратегии и WinDivert из служб
  - **`Check Status`** — просмотр состояния обхода и служб, включая стратегию в автозапуске и WinDivert
  - **`Game Filter`** — изменение режима обхода для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После смены режима стратегию необходимо перезапустить.**  
  В скобках отображается текущий статус — включено или выключено.
  - **`IPSet Filter`** — управление обходом сервисов, перечисленных в `ipset-all.txt`.  
  Это может пригодиться при диагностике ресурса, который без zapret работает, а с ним — нет.  
  В скобках указывается активное состояние:
    - `none` — ни один IP не проходит проверку
    - `loaded` — IP проверяются на наличие в списке
    - `any` — под фильтр попадает любой IP  
  - **`Auto-Update Check`** — включение или отключение автоматической проверки обновлений
  - **`Replace active fakes`** — замена текущего фейка на другой файл из каталога `bin`
  - **`Update IPSet List`** — получение актуального `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновление hosts <ins>**для исправления веб-версии Telegram и подключения к голосовым чатам Discord**</ins>
  - **`Check for Updates`** — ручная проверка наличия обновлений
  - **`Run Diagnostics`** — поиск распространённых причин неисправности zapret.  
  В завершение можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает вернуть неожиданно прекратившуюся работу
  - **`Run Tests`** — запуск проверки стратегий:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска `general*` ничего не происходит

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe. Его можно увидеть на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/bondpythonbear/zapret-discord-youtube/issues/522)

### Не удалось подобрать стратегию
- Откройте командную строку с правами администратора
- По очереди выполните следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts окажется устаревшим, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота
  - С правами администратора откройте текстовым редактором файл `hosts` в созданной папке
  - Вставьте скопированный текст в конец файла `hosts` или замените ранее добавленные аналогичные строки
  - Сохраните файл и проверьте подключение ещё раз. Если проблема останется, убедитесь, что изменения действительно записались.

#### Работа не гарантируется. Если этот способ не помог, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/bondpythonbear/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Работа стратегий со временем может прекращаться.**
> Стратегия способна функционировать некоторое время, а затем перестать работать после её обнаружения.
> В проекте собрано много вариантов обхода. Если готовые варианты не помогают, создайте собственную стратегию на основе одной из них, изменив параметры.
> Описание параметров стратегий находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` -> `Run Diagnostics` проверьте, нет ли ошибок

- Удостоверьтесь, что нужный адрес присутствует в списках доменов или IP

- Попробуйте другие стратегии, включая **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация есть в [#765](https://github.com/bondpythonbear/zapret-discord-youtube/issues/765)

### Как полностью переустановить или обновить проект?
- Сохраните добавленные вами ресурсы и данные
- Перезагрузите устройство
- Откройте `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; если найдены ошибки, устраните их, затем в конце выберите Y
- Удалите каталог zapret
- Скачайте свежую версию (`zapret-discord-youtube-...`) [со страницы релизов](https://github.com/bondpythonbear/zapret-discord-youtube/releases)
- Нажмите правой кнопкой по архиву и откройте свойства. Если внизу справа доступен флажок разблокировки, установите его, нажмите применить и затем ОК
- Распакуйте архив в новый каталог в корне диска, не используя пробелы и специальные символы
- Запускайте разные скрипты `general`, проверяя доступ к интернет-ресурсам. Если стратегия не подходит, закройте программу через значок замка на панели задач и выберите другую
- После обнаружения рабочего варианта добавьте его в автозапуск через `service.bat` -> `Install Service` -> нужная стратегия

### Игра или приложение не работает при включённом zapret

- Проверьте в `service.bat`, что для `Game Filter` установлено **`disabled`**, а для `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о проблеме с WinDivert

- Воспользуйтесь инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё числится среди служб

1. В командной строке Windows, открытой через Win+R и `cmd`, найдите имя службы:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS настроен](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал активно бороться с такими расширениями.
- Переберите остальные стратегии, особенно если ранее всё работало.
- См. также [#251](https://github.com/bondpythonbear/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS включён](#%EF%B8%8Fиспользование)
- Сначала желательно определить стратегию, на которой открывается сайт YouTube, и запустить её
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord
- Проверьте, изменилось ли состояние приложения Discord после очистки кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей
- Если Discord не открывается и в браузере, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/bondpythonbear/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/bondpythonbear/tg-ws-proxy)
- Либо воспользуйтесь бесплатными MTProto-прокси, доступными в интернете

### Не запускаются игры

Игр много, поэтому проверить и исправить каждую из них отдельно невозможно.

Обычно стоит сделать следующее:
- через `service.bat` обновить ipset и активировать `Game Filter`
- если результата нет, дополнительно включить `ipset any`

Учтите, что режим `ipset any` способен нарушить открытие множества сайтов. Не оставляйте его включённым постоянно. Определите IP-адреса, которые использует конкретная игра, и внесите их в `ipset-all.txt`.

Если это не решило проблему, создайте обсуждение в разделе [Discussions](https://github.com/bondpythonbear/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### В списке нет моей проблемы

- Оформите обращение [здесь](https://github.com/bondpythonbear/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены, которые нужно исключить, например когда сеть уже указана в `ipset-all.txt`, но отдельный домен фильтровать не требуется
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, подлежащие исключению
  - Файлы **`*-user.txt`** будут автоматически созданы при первом запуске `zapret` или `service.bat`
