>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) из репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Ряд антивирусов классифицирует файлы WinDivert как инструменты повышенного риска или хакерские утилиты. В результате файл может быть удалён и отправлен в карантин. Название обнаружения обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог zapret в исключения антивируса либо отключите обнаружение PUA — потенциально нежелательных приложений. Например, в Kaspersky есть настройка "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно настраиваете исключения, предпочтительнее добавить исключение; если назначение параметров вам не вполне понятно, рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS).
    * В Chrome активируйте пункт "Использовать безопасный DNS" и укажите поставщика, отличного от "Поставщик по умолчанию".
    * В Firefox включите "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
    * Windows 11 позволяет включить Secure DNS непосредственно в параметрах системы — [инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 это рекомендуемый вариант.
    * Владельцам роутеров Keenetic нужно включить в настройках параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно.

2. Загрузите zip- или rar-архив со [страницы последнего релиза](https://github.com/bondpythonbear/zapret-discord-youtube/releases/latest).

3. Откройте свойства загруженного архива и отметьте "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот пункт можно не выполнять.

4. Извлеките архив в каталог, в пути к которому нет кириллицы и специальных символов.

5. Запустите необходимый файл.
    * Чтобы найти подходящую стратегию, откройте **`service.bat`** и выберите `Run Tests` -> `Standard tests` -> `All configs`.
    * Для включения автозапуска используйте **`service.bat`** -> `Install Service` и затем выберите нужную стратегию.

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) — запуск стратегии напрямую.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для вашей системы**.

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавление выбранной стратегии в автозапуск через services.msc</ins>
  - **`Remove Services`** — удаление стратегии и WinDivert из служб
  - **`Check Status`** — просмотр состояния обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** — смена режима обхода для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После изменения параметра стратегию необходимо перезапустить.**  
  Текущее состояние функции указано в скобках: включена или выключена.
  - **`IPSet Filter`** — выбор режима обработки сервисов из `ipset-all.txt`.  
  Опция полезна во время диагностики, если ресурс без zapret открывается, а с ним — нет.  
  В скобках отображается текущий режим:
    - `none` — IP-адреса не проходят проверку
    - `loaded` — адрес проверяется на наличие в списке
    - `any` — под фильтр попадает любой IP-адрес  
  - **`Auto-Update Check`** — включение или отключение автоматической проверки обновлений
  - **`Replace active fakes`** — замена текущего фейка на другой файл из каталога `bin`
  - **`Update IPSet List`** — загрузка актуального `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновление hosts <ins>**для восстановления веб-версии Telegram и соединения с голосовым чатом Discord**</ins>
  - **`Check for Updates`** — ручная проверка новых версий
  - **`Run Diagnostics`** — поиск распространённых причин неисправности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает при внезапном прекращении работы приложения.
  - **`Run Tests`** — запуск проверки стратегий:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска `general*` ничего не меняется

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe, который можно заметить на панели задач.  
Если этого не произошло, обратитесь к [#522](https://github.com/bondpythonbear/zapret-discord-youtube/issues/522).

### Ни одна стратегия не работает
- Откройте командную строку с правами администратора.
- По очереди выполните следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезагрузите компьютер.

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если файл hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося блокнота.
  - Откройте файл `hosts` в созданном каталоге через текстовый редактор, запущенный от имени администратора.
  - Вставьте скопированный текст в конец `hosts` или замените ранее добавленный аналогичный фрагмент.
  - Сохраните файл и снова проверьте соединение. Если результата нет, убедитесь, что изменения действительно сохранились.

#### Работа не гарантируется. При отсутствии результата используйте [версию Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/bondpythonbear/tg-ws-proxy) либо с любым публичным прокси.

### Обход не запускается или раньше работал, а теперь нет

> [!IMPORTANT]
> **Стратегии не обязательно работают постоянно.**
> Обнаружение конкретной стратегии может произойти со временем, поэтому рабочий вариант иногда перестаёт давать результат.
> В репозитории есть множество стратегий обхода. Если готовые варианты не помогают, создайте новую стратегию на основе одной из существующих и измените её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте сообщения об ошибках через `service.bat` -> `Run Diagnostics`.

- Убедитесь, что нужный адрес присутствует в списках доменов или IP.

- Испытайте другие стратегии, например **`ALT`** или **`FAKE`**.

- Выполните полную переустановку по инструкции ниже.

- Дополнительная информация есть в [#765](https://github.com/bondpythonbear/zapret-discord-youtube/issues/765).

### Как полностью переустановить или обновить проект?
- Сохраните добавленные вами ресурсы и данные.
- Перезапустите устройство.
- Выполните `service.bat` -> `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки, а в конце ответьте `Y`.
- Удалите старую папку zapret.
- Загрузите свежую версию [со страницы релизов](https://github.com/bondpythonbear/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`).
- Нажмите правой кнопкой мыши по архиву и откройте свойства. Если в нижней части окна есть пункт разблокировки, отметьте его, нажмите "Применить" и затем "ОК".
- Распакуйте архив в новый каталог в корне диска. В пути не должно быть пробелов и специальных символов.
- По очереди проверьте разные скрипты `general`. Если интернет-ресурсы не открываются, закройте программу через значок замка на панели задач и попробуйте другую стратегию.
- После выбора рабочего варианта включите автозапуск через `service.bat` -> `Install Service` и укажите нужную стратегию.

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё числится среди служб

1. Узнайте имя службы в командной строке Windows, открыв её через Win+R и введя `cmd`:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал активно с ними бороться.
- Переберите остальные стратегии, особенно если выбранный ранее вариант перестал работать.
- Также смотрите [#251](https://github.com/bondpythonbear/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что настроен [Secure DNS](#%EF%B8%8Fиспользование).
- Для начала определите стратегию, на которой открывается YouTube, и запустите её.
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord.
- Проверьте, заработало ли приложение после очистки кэша.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей.
- Если Discord не работает и в браузере, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- Дополнительные сведения: [#252](https://github.com/bondpythonbear/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/bondpythonbear/tg-ws-proxy).
- Другой вариант — воспользоваться бесплатными MTProto-прокси из интернета.

### Не запускаются игры или нет соединения с ними

Игр много, поэтому проверить и исправить каждую из них невозможно.

Наиболее общий порядок действий:
- через `service.bat` обновите ipset и включите `Game Filter`;
- если это не помогло, дополнительно включите режим `ipset any`.

Учитывайте, что `ipset any` может нарушить доступ к множеству сайтов. Не оставляйте этот режим включённым постоянно. Лучше выяснить IP-адреса, используемые конкретной игрой, и добавить их в `ipset-all.txt`.

Если проблема сохраняется, создайте тему в разделе [Discussions](https://github.com/bondpythonbear/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи от других игроков.

### В списке нет подходящего решения

- Опишите проблему [здесь](https://github.com/bondpythonbear/zapret-discord-youtube/issues).

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса для обхода можно указать в следующих файлах:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены, которые нужно исключить, например когда IP сети есть в `ipset-all.txt`, но конкретный домен фильтровать не требуется
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, подлежащие исключению
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
